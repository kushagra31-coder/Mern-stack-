# Smart Portfolio Dashboard - TSX & Typed Components

## Overview
A financial portfolio dashboard built with React and TypeScript, 
demonstrating type-safe components, props interfaces, and state typing.

## Features
- Typed functional and class components
- Strict props interfaces for all components
- Type-safe state management
- Add, remove, and update assets

## Components
- **AssetCard** - Displays individual asset information
- **AssetList** - Renders list of all assets
- **AssetForm** - Class component to add new assets
- **AssetEditor** - Class component to edit existing assets
- **PortfolioSummary** - Shows total value and average change

## Tech Stack
- React 18
- TypeScript
- Vite

## Setup
npm install
npm run dev
