# Medix Patient Portal - Routing

## Overview
A patient portal built with React Router and TypeScript
demonstrating type-safe route parameters.

## Features
- Dynamic route parameters
- Type-safe useParams
- Patient and Doctor navigation
- Parameter validation

## Components
- **PatientList** - Lists all patients
- **DoctorList** - Lists all doctors
- **AppointmentDetails** - Shows appointment by ID
- **DoctorPatientDetails** - Shows doctor-patient page

## Tech Stack
- React 18
- TypeScript
- React Router DOM
- Vite

## Setup
npm install
npm run dev
