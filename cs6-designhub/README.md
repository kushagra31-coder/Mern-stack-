# DesignHub - Zustand Slices & Modular State

## Overview
A collaborative design platform built with React and
TypeScript, demonstrating Zustand slices for modular
state architecture.

## Features
- Modular Zustand slices per feature
- User authentication slice
- Design files management slice
- Comments slice with file filtering
- Notifications slice

## Store Slices
- **userSlice** - User auth state
- **fileSlice** - Design files management
- **commentSlice** - File comments
- **notificationSlice** - App notifications

## Components
- **UserProfile** - Login/logout
- **FileList** - Manage design files
- **CommentsPanel** - File comments
- **NotificationsPanel** - Read notifications

## Tech Stack
- React 18
- TypeScript
- Zustand
- Vite

## Setup
npm install
npm run dev
