# NewsFleet Dashboard - Testing & Debugging React Apps

## Overview
A real-time newsroom dashboard built with React and 
TypeScript, demonstrating Jest testing, linting, 
and debugging best practices.

## Features
- Article approval workflow
- Comment posting system
- Jest unit and integration tests
- Custom hooks with tests
- Component testing with React Testing Library

## Components
- **ArticleCard** - Displays article with approve button
- **ArticleApproval** - Manages approval state
- **CommentBox** - Input for posting comments

## Hooks
- **useApproval** - Custom hook for approval state

## Tests
- **ArticleCard.test.tsx** - Component rendering tests
- **ArticleApproval.test.tsx** - Approval workflow tests
- **CommentBox.test.tsx** - Comment posting tests
- **useApproval.test.ts** - Custom hook tests

## Tech Stack
- React 18
- TypeScript
- Jest
- React Testing Library
- Vite

## Setup
npm install
npm run dev

## Run Tests
npm test

## Learning Outcomes
- Jest setup with TypeScript
- Component and hook testing
- React Testing Library usage
- Debugging React applications
